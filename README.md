# 🛠️ JU Smart Tools

JU Smart Tools is a free, web-based toolkit that brings together everyday image, PDF, and document tools in one place.

**🔒 Privacy first:** All processing happens inside your browser. Your files are never uploaded to any server.

🌐 **Live Demo:** https://ershubamdigra.github.io/JU-Smart-Tools/

## ✨ Features

### 🖼️ Image Tools
- **Resize Images**: change the dimensions of your images
- **Image to PDF**: convert images into a PDF

### 📄 Document Conversion
- **Doc to PDF**: convert Word documents to PDF
- **PDF to Word**: convert PDF files to Word
- **PowerPoint to PDF**: convert PPTX presentations to PDF

### 📑 PDF Tools
- **Merge PDFs**: combine multiple PDFs into one
- **Split PDF**: separate pages from a PDF
- **Compress & Resize PDF**: reduce PDF file size
- **Multiple Pages Per Sheet**: print several pages on a single sheet
- **Add Image to PDF**: insert an image into a PDF
- **Sign PDF**: add your signature to a PDF
- **Fill PDF Form**: fill out PDF forms

### 🔳 Utilities
- **QR Code Generator**: create QR codes instantly

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/ershubamdigra/JU-Smart-Tools.git
   ```
2. Open `index.html` in your browser.

No installation or server is required. An internet connection is needed because some libraries are loaded from a CDN.

## 🧰 Tech Stack

- HTML, CSS, and vanilla JavaScript
- [pdf-lib](https://pdf-lib.js.org/), [PDF.js](https://mozilla.github.io/pdf.js/), [jsPDF](https://github.com/parallax/jsPDF)
- [Mammoth.js](https://github.com/mwilliamson/mammoth.js), [docx-preview](https://github.com/VolodymyrBaydalka/docxjs)
- [html2canvas](https://html2canvas.hertzen.com/), [JSZip](https://stuk.github.io/jszip/)
